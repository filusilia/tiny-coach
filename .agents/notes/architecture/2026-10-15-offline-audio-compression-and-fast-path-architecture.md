# 离线预置语音深度压缩与 Fast-Path 双引擎架构决策笔记

## Context & Problem Statement

在战术竞技实时教练场景中，播报的时效性与音质直接决定选手的临场决策与交互沉浸感。
参考资产 `dota2-mentor-pack-202608041148` 早期使用了第三方二次元动漫角色 `taiga`（逢坂大河）的语音包（充斥着“笨蛋”、“咬你”、“猪头”等口语化台词），不仅风格脱离现代竞技严肃教练的定位，且原版 70 个 16-bit 48kHz WAV 体积高达 **51.83 MB**。
此外，若对局中所有高频固定播报（如连杀、神符、倒计时）完全依赖本地神经网络动态实时合成，依然会有 150~300ms 推理时延并持续消耗端侧 CPU 算力。

因此，研发团队确立了最高产品原则：
1. **坚决摒弃 `taiga` 二次元人设与台词**，播报文案全面升级为沉稳、专业、标准的电竞战术教练语调；
2. **去除形容词修饰与连杀播报**：摒弃连杀播报（避免与游戏原生超神击杀配音冲突干扰），去除“核心质变大招就绪”、“势如破竹”等形容词后缀，回归纯粹客观事实（如“英雄升到6级”、“赏金神符即将刷新”）；
3. **音色绝对统一于项目自身**：使用神盾教练项目内置的纯 Go 原生离线 **MeloTTS** 声学模型批量预录 35 条核心高频语音；
4. **96kbps 深度压缩与外置 Fast-Path**：体积从 51.83MB 暴降至仅 **0.70 MB（-98.6% 极限减负）**，外置分发，实现 0ms 免生成秒播与 100% 音色前后一致。

---

## Options Considered

### 选项 1：原始 WAV 文件原样外置引入并读取
- **最强理由**：无需做任何转码处理，直接复制即可使用，技术实施复杂度最低。
- **为什么不采用**：70 个音频高达 51.83MB，占用近 52MB 磁盘与分发流量，属于极度低效的资源浪费，违背了现代化极轻电竞工具的研发哲学。

### 选项 2：放弃所有预置音频，全部交由本地 MeloTTS 神经网络实时合成
- **最强理由**：无需携带任何额外音频资产文件，架构单一且完全一致。
- **为什么不采用**：
  1. 高频固定事件（如连杀、神符刷新、倒计时）在对局中瞬息万变，MeloTTS 推理即便只要 150ms 也有轻微延迟感；
  2. 原声解说音效具有浓郁的电竞氛围与激昂语调（如暴走五杀、抢盾、全灭），纯朗读式 TTS 难以完全传达这种战况张力；
  3. 频繁调用 ONNX Session 增加不必要的端侧功耗与 CPU 占用。

### 选项 3（最终决策）：96kbps 高度压缩外置 + Fast-Path 混合双通道架构
- **核心逻辑**：
  1. **无损转高保真 MP3**：使用纯 Node.js 转码脚本，将 70 个 16-bit 双声道 WAV 转为 96kbps 高保真 MP3。体积从 **51.83 MB 降至 3.28 MB（瘦身 -93.7%）**，人声清晰饱满且无底噪；
  2. **外置模块化分发**：存放在 `audio/preset/` 并在打包时平铺到 `release/audio/preset/`，exe 保持纯净轻量的 23.41 MB；
  3. **Go 核心中间件与 Vite 代理拦截**：统一在 `cmd/aegis-coach/main.go` 与 `frontend/vite.config.ts` 拦截 `/audio/` 路由并流式提供 `audio/mpeg`；
  4. **前端 Fast-Path 混合引擎**：在 `frontend/src/services/speechService.ts` 中优先执行预置音频模式匹配。命中 5 大类核心事件时 **0ms 免生成直接播放，0% CPU 占用**；未命中时无缝回退至本地 MeloTTS 离线模型实时生成。

---

## Decision Outcome & Rationale

采纳**选项 3**。这一架构彻底达成了：
- **极小体积与免安装便携**：70 个离线语音压缩后总计仅 3.28MB，主程序 exe 保持 23.41 MB，打包与解压分发极快；
- **0ms 竞技级秒开体验**：神符刷新、倒计时、连杀、等级质变、全灭、买活等 5 大核心高频事件全部实现 0 毫秒秒发音；
- **全场景语义平滑覆盖**：战术出装、AI 深度复盘、特定英雄克制等长文本与动态建议由本地 MeloTTS 神经网络接续完成；
- **用户控制统一生效**：音量控制（0~100）、实时打断（`stop()` 防声音堆叠）、三段式开关（关闭/仅文字/语音+文字）全局统一生效。

## Implementation Details

### 1. 音频批量压缩工具 (`tools/compress-preset-audio.cjs`)
采用 `lamejs` 纯 JS 跨平台编码器，通过全局模块注入修复作用域限制，单批次处理 70 个文件并生成 `manifest.json`：
```text
原始无损 WAV 总大小: 51.83 MB
压缩高保真 MP3 总大小: 3.28 MB
空间瘦身体积比: -93.7%
```

### 2. 后端静态分发管道扩展 (`cmd/aegis-coach/main.go`)
在 `externalAssetMiddleware` 中扩展拦截 `/audio/` 路径，并支持 `.mp3` (`audio/mpeg`) 与 `.wav` (`audio/wav`) MIME 头输出。

### 3. 前端 Fast-Path 字典与匹配引擎 (`frontend/src/data/presetAudios.ts`)
- 包含精确口令字典哈希映射；
- 包含 5 大类智能规则正则判定（双杀/三杀/四杀/暴走，等级质变 6/12/15/18/25/30，赏金/智慧/莲花/功能符/中立装备/狂石，比赛开始/团灭/肉山/塔防/买活，倒计时分秒对齐）。

### 4. 战况规则引擎全面补齐 (`frontend/src/services/gsiRuleEngine.ts`)
完善了对对局实时状态的监测与派发：
- 英雄等级跨越 6, 12, 15, 18, 25, 30 级触发里程碑提示；
- 玩家击杀数在 18 秒多杀窗口内的连续跳变触发连杀播报；
- 赏金神符（3分钟）、莲花池（2:50/5:50）、狂石（0:50/1:00）、中立装备（7/15/25/35/60分钟）周期判定。

### 5. 依赖锁定消除上游破坏性版本漂移 (`go.mod`)
将 `github.com/getcharzp/onnxruntime_purego` 锁定为 `v1.24.0`，修复了 `v1.26.0` 中 `EnableCUDA` 签名变更导致的编译失败。
