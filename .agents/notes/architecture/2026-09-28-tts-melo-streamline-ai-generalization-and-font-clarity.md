# Agent Note: TTS 极简双选 (MeloTTS 原生/Edge)、AI 通用解耦去特定化与首选项文字锐化重构决策笔记

Status: implemented
Date: 2026-09-28
Class: architecture

## 问题背景与因果机制分析

根据实战体验与产品定位，系统在以下关键模块暴露出亟需治理的问题：

1. **战术词典发音叠词 Bug（“肉山大魔，已刷新” -> “肉山大魔王大魔已刷新”）**：
   - **根本原因**：`normalizeTacticalSpeech` 采用简单的全字字符串替换（`result.replaceAll('肉山', '肉山大魔王')`）。当用户输入包含部分衍生词（如“肉山大魔”）或已包含全称时，字串被强制拼接成“肉山大魔王” + 原有后缀“大魔”，产生极其怪异的叠词；同时旧词典错误将动词“刷新”映射为装备“刷新球”，导致所有包含“已刷新”的战术通报全部被污染成“已刷新球”。
   - **治理机制**：彻底移除动词“刷新”、“买活”、“盾”等日常词汇的误杀替换；针对“肉山”采用正规贪婪整词归一化正则 `/肉山(?:大魔(?:王)?)?/g`，无论输入“肉山”、“肉山大魔”还是“肉山大魔王”，均唯一幂等映射为“肉山大魔王”，绝不产生重复叠词；所有英文缩写通过单词边界严格匹配。

2. **TTS 页面过度工程化与技术术语堆砌**：
   - 旧界面暴露了 ONNX、Runtime、dll 路径、ModelScope 下载按钮、第三方 OpenAI/CosyVoice/ChatTTS 各种复杂协议端点与配置，增加了电竞玩家的使用认知负担；
   - 玩家只需要极其直观的两种语音体验：
     1. **Edge 本机语音**（系统内置、极速灵敏、免配置）；
     2. **超保真拟人**（基于 Go-Speech 本地原生 MeloTTS，由代码后台自动静默拉取并装载，微秒级离线拟人发音）。
   - 彻底剔除 Piper 纯中文及外部 HTTP 复杂协议，所有权重与运行时由后台静默闭环处理，页面严禁出现技术术语。

3. **AI 页面测试数据污染与特定厂商绑定倾向**：
   - 严禁将调试用的测试端点与 Key 吸入项目界面；
   - 严禁出现“下载模型”等本地模型拉取负担；
   - 严禁明确指定或偏向任何特定厂商 AI（如 ds / DeepSeek 等特定预设），全面转向支持标准通用 Response API（OpenAI 兼容协议规范），用户自由配置端点与模型。

4. **首选项（Preferences）视觉模糊与对比度衰减**：
   - 旧界面存在较多 `text-2xs` (10px)、低对比度 `text-slate-400` / `text-slate-500` 以及暗色背景融合，导致在 Windows 125%/150% 高 DPI 缩放屏幕上呈现模糊发虚；
   - 全面引入抗锯齿 `antialiased`，文字等级提高至清晰明亮的 `text-slate-100` / `text-slate-200`，正文基准字号提升至 12px/13px，强化对比度与字符边缘锐利度。

## 曾考虑的替代方案与弃用理由

### 1. 继续在 TTS 界面保留模型下载按钮和多种第三方协议
- **最强理由**：技术极客用户可以自由配置端口、选择 Piper 或 MeloTTS。
- **为何弃用**：神盾教练是服务于电竞对抗的极简专业客户端，不是 AI 调试平台。普通玩家面对复杂的端口、模型权重和下载按钮只会产生困惑和挫败感。后台全自动静默加载 MeloTTS 才能实现真正的“开箱即用”。

### 2. 在词典替换中只做简单的 `includes` 预判
- **最强理由**：实现简单，如果已有“大魔王”就不替换。
- **为何弃用**：无法处理“肉山大魔”这种既有前缀又有非全称后缀的边缘场景，正则贪婪归一化才能在数学上保证输出的绝对唯一性与幂等性。
