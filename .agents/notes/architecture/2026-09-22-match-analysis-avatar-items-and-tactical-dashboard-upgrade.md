# Agent Note: 赛后分析玩家身份大盘布局、对局物品栏与深度战绩指标全景升级

Status: implemented
Date: 2026-09-22
Class: architecture

## 问题背景与因果机制分析

1. **赛后分析页面缺乏当前玩家账号头像与个性化档案，布局缺乏主场沉浸感**：
   - **因果机制分析**：
     - 原 `AnalysisView.vue` 仅在卡片次级标题处显示一串纯文本 `(账号: 12345678)`，未展示玩家的真实 Steam/OpenDota 个人头像与昵称；
     - 玩家进入赛后复盘时，界面感知更接近“公开数据库浏览器”而非“专属电竞教练战术中心”；
     - 战术雷达图与核心战绩指标缺乏统一的身份档案头部 Banner 承载，界面上下视觉比重失衡。

2. **点击载入比赛详情后，十人阵容大盘数据颗粒度不足，缺乏核心物品装备栏与精确对决时间**：
   - **因果机制分析**：
     - Dota 2 赛后复盘与局势推演的核心立足于**出装路线与关键装质变时机**（如 BKB、跳刀、A杖、魔晶等）；
     - 此前十人阵容卡片仅展现了英雄名称、简略 KDA 与净资产数字，**完全缺失了 6 格神装、中立物品以及 A杖/魔晶强化状态**；
     - 缺少精确的比赛开始日期与对决时间戳，仅有持续时长秒数，用户无法快速辨识比赛发生的时间跨度；
     - 缺少关键战术数据：等级 (Level)、正反补 (Last Hits/Denies)、GPM/XPM、英雄伤害 (Hero Damage) 与参战率 (Kill Participation, KP%)。

## 决策方案

### 1. 玩家战术身份档案 Banner 与双栏布局重构
- **玩家身份档案 Banner**：
  - 顶端设立专属选手档案区，呈现 **60x60 高分辨率玩家圆形头像**（带金黄微光双层外环）、加粗玩家昵称、32 位数字账号徽章（支持一键剪贴板复制）与战术风格标签；
  - 集成快速切换/检索玩家 ID 输入框与一键刷新战报按钮；
  - 自动将 OpenDota 拉取的玩家昵称与头像同步保存至 `appStore.settings`，保证多处持久化一致。
- **大盘双栏布局**：
  - **左侧 7 列**：近期场次、综合胜率、场均 K/D/A、综合战损比 4 宫格核心数据，以及 **Top 3 常用英雄池**（带官方头像、胜率、场次，支持点击快捷筛选对局列表）；
  - **右侧 5 列**：纯 SVG 矢量绘制的**五维战术能力雷达图**（参战、发育、击杀、生存、推进），半透明渐变能量光晕与顶点发光标签。

### 2. 对局详情全景战报大盘升级（装备栏、对决时间与多维战绩）
- **比赛元信息栏**：
  - 展现比赛 ID、天辉/夜魇获胜徽章；
  - 格式化呈现**精确对决时间**（如 `2026-09-22 14:35 (2小时前)`）；
  - 呈现游戏匹配模式（如 `天梯全选 (Ranked All Pick)`）与房间类型；
  - 呈现比赛时长与双方击杀总比分。
- **十人全景阵容大盘（天辉方 5 人 + 夜魇方 5 人）**：
  - 引入本地物品常数字典映射（`item_constants.json` 与 `items.json`），将 `item_0` ~ `item_5` 与 `item_neutral` 数字 ID 解析为标准物品短名与中文译名；
  - **严格遵守开工铁律 11**：每个选手行呈现 **6 格标准装备栏 + 1 格中立物品栏**，严格保持官网 4:3 比例规范（36x27 紧凑格），空槽位显示深色凹槽，悬浮展示物品中文名与 Tooltip 浮层；
  - 动态点亮阿哈利姆神杖（A 杖）与魔晶激活徽章；
  - 全面展示 **等级 (Lv)**、**K / D / A**、**参战率 (KP%)**、**净资产**、**GPM / XPM**、**正反补** 与 **英雄伤害**；
  - 保持选定视角选手的高亮光晕与操纵者标识，无缝串联 Solution Hierarchy AI 深度复盘报告。

## 曾考虑的替代方案

### 1. 使用第三方表格组件（如 Element Plus / Naive UI）展示十人战报
- **为何最强**：表格自带列排序与现成排版。
- **为何放弃**：引入外部 UI 库会破坏神盾教练轻量级原生架构，并破坏暗黑电竞 HUD 设计风格；手写精巧的 Flex/Grid 卡片流能实现像素级对齐的 4:3 物品格与深色高对比悬浮卡，体积更轻、控制力更强。

### 2. 仅在选中的单一选手卡片中展示物品，其余选手省略
- **为何最强**：十人全部渲染 7 格物品需要更多 DOM 节点。
- **为何放弃**：Dota 2 复盘的核心是双方阵容的**装备博弈与对策克制**（如敌方核心是否出到了 BKB/大推推、我方辅助是否有微光/吹风等）；仅展示单一选手无法评估整盘对局的装备走势，必须十人完整展现。
