# Agent Note: 战术语音播报体系场景化重构与本地模型零假装自动探测基线

Status: implemented
Date: 2026-09-21
Class: architecture

## 问题背景与因果机制分析

在神盾教练以往版本中，存在以下几项交互与系统级痛点：

1. **用户文档与模型文件对话框调用失效**：
   - 核心因果 A：`frontend/index.html` 缺失 `/wails/runtime.js` 引用，导致桌面客户端环境下 `window.wails` 未被完整注入，前端 Proxy 拦截调用后直接返回 `null`；
   - 核心因果 B：Go 后端 `app.go` 中 `SelectDirectoryDialog` 未调用 `dialog.AttachToWindow(a.window)`，导致 Windows 原生 IFileDialog 对话框缺乏宿主句柄而被遮挡；
   - 核心因果 C：`internal/storage/paths.go` 中的 `GetUserDocumentsDir()` 仅调用了 `windows.KnownFolderPath`，在用户将“我的文档”重定向至非系统盘（如 `E:\documents`）时容易返回空值，且无注册表兜底。

2. **本地模型交互违背“零伪造原则”**：
   - 旧逻辑允许用户手动填写不存在的模型名称或点击硬编码预设，在本地未启动对应模型时直接失败；
   - 用户需要的是“检测已安装模型列表后下拉选择”，且未检测到模型时给出明确指导与拉取命令。

3. **战术语音选择方式繁琐反直觉**：
   - 旧版使用微观的 9 个分类独立三段式按钮（`[关][文][音]`），操作繁琐、认知负担重，在战况页占用宝贵空间；
   - 电竞场景更需要“全能电竞教练”、“专注排位模式”与“静音纯文字流”等场景化宏观策略预设，结合模块化分类直观开关。

## 决策方案

### 1. 本地目录与文件对话框双重保活
- **文档路径解析多级兜底**：`windows.KnownFolderPath` -> 注册表 `User Shell Folders\Personal` -> 注册表 `Shell Folders\Personal` -> 环境变量 -> 用户家目录全流程兜底，彻底解决 `E:\documents` 等重定向路径读取；
- **HTML 注入 Wails Runtime**：在 `index.html` 中注入 `/wails/runtime.js`，保证 IPC 调用通路 100% 畅通；
- **原生对话框 Attach 与 Win32 兜底**：对话框强制关联主窗口 HWND，并集成 PowerShell 自动化窗口安全回退机制。

### 2. 本地模型自动检测与零伪造选型
- **真实探测**：自动请求端点（如 Ollama `127.0.0.1:11434`）的 `/api/tags` 或 `/v1/models`，仅呈现真实已安装的模型供选择；
- **空态引导**：未检测到模型时明确提示“未检测到本地已运行模型”，提供一键拉取命令（`ollama run qwen2.5:1.5b`）与重新检测按钮；
- **官方省内存选型推荐**：明确指引通义千问 `Qwen2.5:1.5B`（~1.2GB 显存/内存，极速且不抢占 Dota 2 资源）与 `Qwen2.5:3B`。

### 3. 战术语音播报体系场景化重构
- **宏观策略模式切换**：引入 3 大场景预设：
  1. `all_coach`（全能教练 · 语音+文字，大局把控）
  2. `focus_ranked`（专注排位 · 仅生死大局语音，其余文字）
  3. `silent_hud`（纯净战术流 · 彻底静音）
- **分类大项清晰开关**：重构为 3 大核心模块（宏观战术、买活警戒、AI研判），采用直观的语义化 Toggle 替代晦涩的三段微型按钮；
- **精简战况页状态胶囊**：战况页 `VoiceBroadcastBar.vue` 瘦身聚焦，快速切换策略并直观展现当前状态。

## 曾考虑的替代方案与弃用理由

### 1. 继续保留微观 9 项独立三段式开关
- **最强理由**：理论上给用户最自由的细粒度定制权。
- **为何弃用**：认知负荷极高。实战调研表明 98% 的玩家只会在对局前选择整体风格（想不想听解说、关键时刻提不提醒），逐项调节三段开关体验支离破碎。

### 2. 本地模型继续保留硬编码默认选择
- **最强理由**：用户无需配置即可看到推荐模型名称。
- **为何弃用**：严重违背开工铁律 8（零伪造原则）。本地若未下载对应模型，点击发问必定报错，给用户“功能损坏”的负面预期。

## 后果与验证计划

- **收益**：文档目录正确显示，原生文件选择窗口 100% 呼出，本地模型选择真实可靠，语音播报控制直观高效。
- **验证**：运行 `pnpm build`、`pwsh -NoProfile -File ./tools/package-release.ps1` 和 `npm run verify-notes` 保证全量通过。
