# Agent Note: 英雄详情 46 开分栏紧凑布局重构 (左侧英雄信息 40% / 右侧技能信息 60%)

Status: implemented
Date: 2026-09-28
Class: architecture

## 问题背景与因果机制分析

在神盾教练英雄资料库视图中，此前英雄详情页采用全屏纵向单列自上而下堆叠的布局：
1. 顶部：`HeroStatsCard`（英雄基础属性、定位与背景传记，横跨 100% 宽度）；
2. 中部：`AbilityShowcase`（天赋树与官网 `AbilityRight` 技能详情展台，横跨 100% 宽度）；
3. 底部：`HeroBuildPanel`（英雄宏观技巧与推荐出装，横跨 100% 宽度）。

这种自上而下长距离垂直堆叠的布局存在以下核心痛点：
- **纵向滚动深度过大**：用户在查看英雄的三维属性时无法同时对照技能数值，每次点击技能需要大量上下滚动滚轮，视觉焦点频繁跳跃；
- **宽屏空间浪费**：在主流 1080P/2K/4K 宽屏客户端下，单列内容横向被强行拉伸，大片水平区域留白过多，信息密度偏低；
- **英雄与技能割裂**：英雄的基础定位、出装流派与核心技能原本是一体化战术参考，割裂在不同的纵向屏障中破坏了查阅连贯性。

在首次实现尝试中，曾使用 `grid-cols-1 xl:grid-cols-10` 结合 `xl:col-span-4` / `xl:col-span-6`，但由于客户端主窗口默认宽度为 1280px，扣除 Windows 原生边框与侧边导航栏后，详情容器的实际视口宽度处于 1000px~1200px 区间，未能触发 `xl:`（>=1280px）媒体查询断点，导致界面依然以 `grid-cols-1` 退化为上下堆叠。必须彻底移除断点依赖，使用无条件原生 flex 4:6 分割。

## 决策方案

### 1. 英雄详情整体 46 开左右分栏 (无条件 Flex 弹性盒子)
- **外层容器**：`class="flex flex-row gap-4 items-start w-full"`
- **左侧 40% (`style="flex: 4 4 0%; min-width: 0;"`)：英雄战术与基础信息**
  - 上部放置 `HeroStatsCard`：展示英雄头像、中文大名、官方更新徽标、攻击类型、上手难度、核心定位、力量/敏捷/智力三维成长、1 级基础战斗数值与折叠式背景传记；
  - 下部紧随放置 `HeroBuildPanel`：展示宏观实战技巧战略与当前版本分阶段热门出装路线；
- **右侧 60% (`style="flex: 6 6 0%; min-width: 0;"`)：官方技能全景展台**
  - 承载 `AbilityShowcase`：顶部容纳天赋树与全部技能切换栏，下方展开官网标准 `AbilityRight`、`GenericValues`、`SpecificValues`、冷却与蓝耗底栏、神杖与魔晶强化卡片、实战要点 Tips 与机制注解 Notes。

### 2. 紧凑化视觉与网格自适应调优
- **`HeroStatsCard` 紧凑优化**：优化卡片内边距与网格排布，力量/敏捷/智力三维与 1 级数值在 40% 宽度下形成紧密工整的矩阵，去除大块留白；
- **`HeroBuildPanel` 紧凑优化**：优化为单列垂直流式卡片，出装格子更紧凑，与上方属性卡片浑然一体；
- **`AbilityShowcase` 紧凑优化**：内边距收敛为 `p-4`，技能大图、描述与属性矩阵比例更协调，大幅缩短纵向高度。

## 曾考虑的替代方案

1. **方案一：继续使用媒体查询断点 (如 `lg:grid-cols-10` 或 `md:grid-cols-10`)**
   - *最强理由*：纯 class 类名控制。
   - *为什么不用*：各个用户的屏幕分辨率和 DPI 缩放比例不同，桌面客户端窗口尺寸多变，只要宽度稍低一点就会意外退化为上下排列；用户指令明确要求“左侧英雄信息，右侧技能信息 46 开”，使用 `flex: 4 4 0%` 与 `flex: 6 6 0%` 可以在任何窗口尺寸下 100% 绝对生效，杜绝断点错位。

2. **方案二：固定高度并在左右各自使用独立滚动条**
   - *最强理由*：左右两边独立滚动，左侧不动右侧动。
   - *为什么不用*：双内部滚动条在桌面端会导致滚轮焦点陷阱，破坏平滑滚动体验。采用整体自适应网格与统一外部滚动更加自然流畅。

## 后果与验证计划

- **正面收益**：用户无论如何缩放窗口，均能在同屏一眼对照英雄基础属性、出装与技能机制，信息密度大幅提升，无需大幅度滚动页面。
- **验证矩阵**：
  - 运行 `npm run verify-notes`：Agent 决策笔记校验通过；
  - 运行 `node scripts/test-hero-ui-redesign.cjs` 及全部自动化测试；
  - 运行 `npm run build`（`vite build`）与打包验证。
