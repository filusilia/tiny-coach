# Agent Note: 赛后复盘全景表格、英雄大图统一、可输入Combobox与物品卡片点击锁定重构

Status: implemented
Date: 2026-09-29
Class: architecture

## 问题背景与因果机制分析

1. **赛后详情数据不对齐与 OpenDota 体验差距**：
   - **因果机制**：旧版 `MatchDetailPanel.vue` 采用多层嵌套的 `flex justify-between` 布局，当玩家昵称长短不一时，每行的弹性容器各自伸缩，导致右侧的 KDA、经济、正反补、伤害与装备格出现严重左右摆动和错位。
   - **解决措施**：参考 OpenDota 官网 Matches 页面，采用带有横向滚动条（`overflow-x-auto`）的标准对齐表格列宽设计。左侧玩家与英雄栏设置固定宽度并支持 `truncate` 省略长昵称，右侧等级、K/D/A、NET、GPM/XPM、LH/DN、DMG、TOWER、装备格均设置固定列宽与精确垂直对齐。
   - **神杖与魔晶图标**：全面引入用户提供的 `/assets/icons/scepter_1.png`（已购买）/ `scepter_0.png`（未购买）与 `shard_1.png` / `shard_0.png`，直观呈现十人装备体系。

2. **比赛 ID 双击复制与顶部 Header 紧凑重构**：
   - **因果机制**：旧版将顶部拆分为“面包屑返回栏”和“战报 Banner”两个独立大卡片，且展示了非核心的“防御塔剩余 11 座”与“数据源认证”，挤占屏幕垂直高度。
   - **解决措施**：合并为单个紧凑卡片，左侧包含返回按钮、比赛 ID（支持双击复制到剪贴板并给出视觉反馈）、胜负徽章与对局模式，右侧收纳总比分、开赛时间与时长，彻底剔除防御塔剩余与数据源展示。

3. **AI 复盘纯化与“思维链”字眼剥离**：
   - **因果机制**：旧版展示了“思维链推演”等不必要的技术术语，且提供了十人视角切换，分散了用户对自身绑定的焦点。
   - **解决措施**：彻底移除“思维链推演”标签与所有思考链字眼；取消十人头像视角切换器，AI 复盘默认且仅针对当前绑定的玩家账号（或当前对局中该玩家操纵的槽位）生成战术报告。

4. **全仓英雄头像统一放大**：
   - **因果机制**：原英雄头像尺寸较小（如 `h-8 w-11`、`h-9 w-13`），在高清屏幕下识别度低，缺乏电竞 HUD 的沉浸感。
   - **解决措施**：将 `MatchDetailPanel`、`RecentMatchList`、`TopHeroesPanel` 等关键位置的英雄头像统一放大（至 `h-11 w-16` / `h-13 w-20`），强化视觉张力。

5. **设置页 Select 原生丑陋与可输入 Combobox 改造**：
   - **因果机制**：旧版使用原生 `<select>` 标签，无法定制暗黑样式，且传统下拉框无法手动键入模型名，需要通过辅助按钮在“手动输入”与“下拉选择”之间痛苦切换。
   - **解决措施**：重构为纯 Vue 3 + UnoCSS 现代电竞暗黑风格的可输入 Combobox，用户既可在输入框中直接键入任意模型名称，亦可点击下拉选择预设模型，彻底移除手动切换按钮。

6. **物品卡片有滚动条但无法滚动的缺陷修复**：
   - **因果机制**：旧版 `ItemsView.vue` 中的 ToolTip 卡片为了避免遮挡鼠标事件，强制设置了 `pointerEvents: 'none'`，且鼠标移出小方格立即触发 `mouseleave` 隐藏卡片，导致内部即便有纵向溢出内容也根本无法被鼠标滚轮滚动。
   - **解决措施**：增加点击物品锁定功能（`pinnedItem`），点击物品后卡片处于 Pin 状态且激活 `pointer-events: auto`，鼠标可直接进入卡片内部进行上下滚动查看长技能描述与进阶配件，点击空白或按 ESC 取消锁定。

## 被否决的备选方案论证

### 方案 A：在 ToolTip 上直接使用延时 mouseleave 允许鼠标滑入
- **最强理由**：无需用户点击，鼠标直接从物品移动到卡片即可滚动。
- **为什么不采纳**：在密集的 56x42 物品网格中，鼠标划过多个物品时会产生大量卡片闪烁与误触，极难精确滑入悬浮卡片；用户明确要求“增加一个点击物品后 卡片不消失的功能”，点击固定（Pin）是桌面端最符合心智模型的精准交互。
