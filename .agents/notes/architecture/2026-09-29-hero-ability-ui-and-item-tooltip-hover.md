# Agent Note: 英雄技能展台排布优化、多级属性独占行与热门装备悬浮窗交互

Status: implemented
Date: 2026-09-29
Class: architecture

## 问题背景与因果机制分析

1. **卡尔（祈求者）等多技能英雄技能栏超出卡片溢出破损**：
   - 卡尔（Invoker）包含 3 个元素基础球（冰/雷/火）、1 个大招（元素祈唤）以及 10 个被祈唤出的法术技能，加上先天技能总计高达 15 个技能；
   - 原 `AbilityShowcase.vue` 中技能图标容器采用 `flex items-center space-x-1.5`，未声明 `flex-wrap`，且每个技能图标固定为 `h-14 w-14`（56x56px）；
   - 在 4:6 分割布局下，右侧技能展台容器宽度约为 550~650px，15 个技能横向排开所需宽度超过 900px，直接撑爆卡片边框并向右溢出视口，破坏了页面整洁度与响应式结构。

2. **技能等级属性变化过多导致双列网格挤压断行**：
   - 卡尔的部分技能（如熔炉精灵、急速冷却、阳炎冲击等）由冰/雷/火三系元素分别决定，等级梯度高达 7~9 级（如攻击力（火）：20 / 30 / 40 / 50 / 60 / 70 / 80 / 90 / 100）；
   - 原布局采用 `grid grid-cols-1 md:grid-cols-2` 且单项为 `flex items-center justify-between`；在半幅宽度（约 260px）内，左侧标签占据一定宽度后，右侧一长串数字无处容纳，导致标签被迫换行破损、长数值被生硬截断或折断，信息难以阅读。

3. **热门推荐出装缺乏深度信息悬浮窗**：
   - 原 `HeroBuildPanel.vue` 中仅渲染了出装阶段图标与单行金币，鼠标悬停只有简单的浏览器原生系统 `:title` 提示；
   - 玩家在查看英雄攻略时，无法获知热门出装的具体属性加成、主动/被动效果技能详情、冷却与魔耗等关键战斗信息，相比于独立物品页体验割裂。

## 决策方案

1. **英雄技能图标栏自适应弹性换行与自适应尺寸设计**：
   - 技能栏容器增加 `flex-wrap gap-2`，确保在任何宽度下技能均整齐包裹换行；
   - 区分常规技能与多技能英雄（当技能总数 > 8 时，如卡尔），自适应调节图标尺寸为精致紧凑的规格（如 `h-11 w-11` 或 `h-12 w-12`），配合清晰的元素发光、金色选中边框与神杖/魔晶角标，既还原 Dota 2 官网紧凑专业的展台风格，又彻底杜绝容器溢出。

2. **智能等级变化属性独占整行排布 (Full Width Row Layout)**：
   - 引入长属性检测机制 `isMultiLevelSpecial(v)`：当属性包含 `/` 数量 >= 4（即 5 级以上）或数值字符串长度超过 22 字符时，判定为多等级复杂属性；
   - 多等级复杂属性设置 `md:col-span-2 col-span-full` 独占整行展示，采用左右舒展或两层清晰排版（左侧高亮标签，右侧清晰展开 9 级等宽金色梯度），使 `20 / 30 / 40 / 50 / 60 / 70 / 80 / 90 / 100` 等所有等级梯度一目了然；普通短属性继续保持紧凑双列网格，兼顾信息密度与阅读体验。

3. **热门推荐出装集成 Dota 2 官方标准高保真物品悬浮窗 (Item Tooltip Hover)**：
   - 在 `HeroBuildPanel.vue` 中挂载全局物品数据字典，通过物品名或英文代号实时命中对应的完整元数据；
   - 鼠标 Hover 热门装备时，即时弹出深色高对比度、带半透明亚克力磨砂质感的官方高保真详情卡片（包含物品大图标、造价、属性加成药丸网格、Liquipedia 风格主动/被动技能渐变卡片、冷却/蓝耗及配件清单）；
   - 计算屏幕视口动态边界（`calculateTooltipPos`），实现自适应防遮挡与防出界，移出即隐，体验极致流畅。
